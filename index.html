O 키로 언제든 열고 닫을 수 있습니다.

선택과 이동

좌클릭유닛 또는 건물 하나를 선택합니다.
좌클릭 드래그범위 안의 아군 유닛을 한꺼번에 선택합니다.
우클릭이동하거나 대상에 맞는 공격·채집·반납·건설 지원·회복 명령을 내립니다.
마우스 휠현재 커서 위치를 기준으로 화면을 확대하거나 축소합니다.
화면 가장자리커서를 가장자리로 옮겨 카메라를 이동합니다.

전투 명령

A → 좌클릭지점까지 이동하며 만나는 적을 공격합니다. 적을 직접 누르면 집중 공격합니다.
적 우클릭선택한 전투 유닛이 해당 적을 집중 공격합니다.
S선택한 유닛의 현재 명령을 즉시 정지합니다.

부대 지정

1~0저장된 부대를 선택하고 해당 위치로 카메라를 이동합니다.
Shift + 숫자현재 선택한 유닛을 기존 부대에 추가합니다.
Ctrl + 숫자현재 선택한 유닛으로 해당 부대를 덮어씁니다.

건설과 생산

일꾼 Z/X/C생산·방어·자원 건물 분류를 선택합니다.
분류 후 Z~B표시된 순서에 맞춰 건물을 선택한 뒤 지면을 좌클릭해 배치합니다.
생산건물 Z~B선택한 생산건물에서 표시된 순서의 유닛을 생산합니다.
Shift세부 건설 목록에서 건설 분류 화면으로 돌아갑니다.
자원 우클릭선택한 일꾼에게 채집 명령을 내립니다.

화면과 정보

P전체화면과 마우스 잠금을 켜거나 끕니다. 잠금 상태는 주황색 커서로 표시됩니다.
O이 조작 가이드를 열거나 닫습니다.
I모든 유닛과 건물의 상세 도감을 열거나 닫습니다.
Esc브라우저의 전체화면 또는 마우스 잠금을 해제합니다.
